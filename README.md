# BlackCatTools

Browser-based utilities, hosted on GitHub Pages: https://theblackcat98.github.io/Online-Tools/

## Apps

- [Color Token Workshop](https://theblackcat98.github.io/Online-Tools/color-token-workshop.html) — guided CSS color-token builder with WCAG/APCA contrast auditing and CSS variable export
- [Mermaid Viewer](https://theblackcat98.github.io/Online-Tools/mermaid-viewer.html) — mobile-friendly Mermaid.js live editor and viewer
- [Image to ICO](https://theblackcat98.github.io/Online-Tools/image-to-ico.html) — convert any image to a multi-size Windows .ico file
- [SVG to ICO](https://theblackcat98.github.io/Online-Tools/svg-to-ico.html) — rasterize an SVG at every icon size into one .ico
- [PNG to SVG](https://theblackcat98.github.io/Online-Tools/png-to-svg.html) — trace a raster image into real vector SVG paths (ImageTracerJS)
- [SVG to STL](https://theblackcat98.github.io/Online-Tools/svg-to-stl.html) — extrude filled SVG shapes into a printable STL with 3D preview (Three.js)
